# SpatialStage 完整部署手册（从 GitHub 到演出）

版本：**v0.4.1** · 分支 **`feat/cue-layers`** · 仓库 <https://github.com/ShawnZ1438/SpatialStage>

这一份手册覆盖从零部署到演出当天的全部步骤。更细的说明（每个参数的含义、AutoCal、故障排查全表）见 [使用、测试与演出部署手册](SHOW_GUIDE.zh-CN.md)。

> **安全第一**：软件的 MAIN MUTE 和 PANIC 只能停掉软件输出。现场必须另外有调音台上的物理静音（M32R 的 Mute Group），并指定专人负责。

---

## 0. 这个版本能做什么

| 功能 | 说明 |
|---|---|
| 四声道空间声 | Mac → M32R USB → 4 路独立输出 → 四角 4 只音箱，以舞台中心的演员为聆听点 |
| 自带演出包 | 仓库里有 20 个音频（`show/audio/`，约 409 MiB）和编好的 20 条 Cue，第一次启动自动导入 |
| 打开即演出 | 每次打开直接进入演出界面；自动连接上次的输出设备并自动预检；MAIN MUTE 保持开着 |
| 每条 Cue 的 ▶ / ■ | ▶ 从头播放、叠加在其他声音上（再点 = 从头重来）；■ 只把这一条淡出（默认 2 秒） |
| 声音不会被动消失 | 默认任何声音只会自己播完，或被 ■ / STOP / PANIC 停掉 |
| GO 顺序播放 | 空格 = GO 按 Cue 列表顺序播放；NEXT 只由 GO / SKIP / 设为 NEXT 改变 |
| 音频库 + 多层 Cue | 音频库管声音设计（电平、裁剪、淡入淡出、循环、立体声）；一条 Cue 最多 32 层，每层有自己的位置/路径、电平、延迟；拖音频到舞台图即可加层 |
| 舞台平面图 | 拖动位置、画移动路径；存储 / 恢复 / 重置 |
| 中 / EN | 右上角切换界面语言，默认中文 |
| 本地模拟 | 没有调音台也能测试：静音模拟、耳机虚拟四音箱监听、录 4 声道 WAV |

## 1. 准备清单

**硬件**
- Mac：Apple Silicon（M1 或更新）推荐，macOS 12.3 或更新；演出时插电源
- USB 线：Mac ↔ M32R（USB-B），不超过 5 m
- Midas M32R：XLR Out 1–4 接 4 只音箱
- 4 只 IBO PS15。**先确认有源还是无源**：iBO PS15 查到的是 15 寸无源箱，无源箱需要 4 路功放（M32R XLR 1–4 → 功放 → 音箱）
- 有线耳机（排练时虚拟四音箱监听；蓝牙耳机延迟大，不建议）
- 卷尺、地胶（标记舞台中心和正前方）
- 可选：XLR 测量话筒（AutoCal）

**网络**：第一次克隆和安装需要联网（下载约 800 MB + Python 依赖）。之后可以完全离线运行。

**场地几何**：6 m × 6 m，四只音箱在四角，都朝向中心。演员活动范围建议半径 1.5–2 m 以内（半径 3–4 m 的圆放不进 6 × 6 m，越靠近某只音箱，声音越被拉向它）。

## 2. 从零安装（只做一次）

打开「终端」（启动台 → 其他 → 终端），逐条执行。

### 2.1 Homebrew 和依赖

还没有 Homebrew 时先装（已装过就跳过）：

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

装完按屏幕最后的提示执行那两行 `eval ...`，然后：

```bash
brew install python@3.12 git ffmpeg portaudio libsndfile
```

- `python@3.12` 必须（支持 3.11–3.13）。
- `ffmpeg` 只在导入 MP3/M4A/AAC 时需要；随包的 WAV/FLAC 不需要。
- `portaudio`、`libsndfile` 一般随 Python 包自带，装上也无妨。

### 2.2 获取代码和演出音频

放在用户目录下（不要放进开了 iCloud 同步的「文稿」「桌面」）：

```bash
cd ~
```

```bash
git clone -b feat/cue-layers https://github.com/ShawnZ1438/SpatialStage.git
```

```bash
cd SpatialStage
```

音频是普通 Git 文件，**不需要 Git LFS**。检查数量和完整性：

```bash
ls show/audio | wc -l
```

```bash
cd show && shasum -a 256 -c SHA256SUMS && cd ..
```

第一条应输出 `20`；第二条每行都应是 `OK`。

### 2.3 安装依赖

在访达里打开 `SpatialStage` 文件夹，双击 **Install SpatialStage.command**（或在终端执行 `./run_mac.command --install-only`）。它会创建 `.venv` 并安装依赖，约 1–3 分钟。

提示「无法打开，因为来自身份不明的开发者」：在文件上 **右键 → 打开 → 打开**，只需一次。提示 `permission denied`：执行 `chmod +x *.command`。

### 2.4 macOS 设置（演出机必须做）

| 设置 | 位置 | 原因 |
|---|---|---|
| 系统输出**不要**选 M32R | 系统设置 → 声音 → 输出，选「Mac 扬声器」 | 否则提示音会从前左、前右音箱出来 |
| 提示音也走 Mac 扬声器 | 声音 → 声音效果 → 播放声音效果的设备 | 同上 |
| M32R 采样率 48 kHz | 实用工具 → 音频 MIDI 设置 → M32R → 格式 48000 Hz | 软件固定 48 kHz |
| 允许配件连接 | 第一次插 M32R 时点「允许」（隐私与安全性 → 允许配件连接） | 否则设备列表里没有 M32R |
| 「终端」麦克风权限（只 AutoCal 需要） | 隐私与安全性 → 麦克风 | 否则录到静音 |
| 勿扰、关闭自动更新、接电源时不睡眠 | 控制中心 / 软件更新 / 电池 | 避免弹窗、重启、睡眠（启动器已用 caffeinate 防睡眠） |

## 3. 启动

双击 **Start SpatialStage.command**。**演出期间不要关闭这个终端窗口**（关掉 = 停止音频引擎）；浏览器可以刷新或关掉再打开，声音不受影响。

| 启动文件 | 作用 |
|---|---|
| **Start SpatialStage.command** | 正式启动，数据在 `~/.spatialstage/projects` |
| **Start Simulation (Mac).command** | 测试启动，数据在仓库里的 `SpatialStage-test-data`，和演出数据隔开 |
| **Stop SpatialStage.command** | 安全停止引擎（只在没有声音、已静音时才停） |
| **Install SpatialStage.command** | 只安装依赖 |

**第一次启动会自动：**
1. 把 `show/audio/` 导入成项目 **Show audio (repository)**：20 个音频进音频库，20 条 Cue 按模板恢复（顺序、标题、电平、位置、路径、预设），四角音箱布局。终端显示 `Repository show: Show audio (repository) (20 cues)`。
2. 打开浏览器 `http://127.0.0.1:8765`，**直接进入演出界面**（默认中文）。

**以后每次启动还会自动：** 重新连接上次用过的输出（M32R / 静音模拟 / 耳机监听）并预检全部音频，底部提示「已自动连接并预检：20 条 Cue，已解码 624.1 MiB」。**MAIN MUTE 始终保持开着**，需要你手动解除。点「断开音频」会让软件忘掉这个设备。

**界面一览**

- 右上角：**✎ 编排 / ▶ 演出**（编排 = 编辑；演出 = 锁定编辑）、**⚙ 舞台设置**、**中 / EN**。网址 `http://127.0.0.1:8765/?mode=edit` 直接打开编排。
- 顶部播放条：NEXT、**FADE GO / CUT GO / STOP / SKIP / PANIC**，以及「⏮ 回到第一条」「从选中 Cue 开始」「▶ 播放选中」「■ 停止选中」。
- 左侧：项目、音频设备、主输出（MASTER 推子、MAIN MUTE、电平表）。
- 中间：舞台平面图；右侧：Cue 列表（每条右边有 ▶ / ■）和设置面板。编排模式下左边还有音频库。

## 4. 不接调音台先测试（任何电脑都可以）

1. 展开顶部 **本地模拟** 面板，点 **连接静音模拟**（以后启动会自动连上）。
2. 点 **✓ 预检 Preflight**：`预检通过：20 条 Cue，20 个文件，已解码 624.1 MiB`。
3. 点左侧 **MAIN MUTE · ON** 解除静音。
4. 点某条 Cue 的 **▶**：右侧显示 LIVE 和进度，CH1–4 电平表会动，地图上出现黄色声源点。点 **■** 淡出。
5. 想用耳机听方位：插耳机 → 本地模拟里选 **虚拟四音箱（耳机）** → 点一次 **连接耳机监听**（列出设备）→ 选耳机 → 再点一次。MASTER 先放在 −30 dB 左右，再解除 MAIN MUTE。**听者 X / Y / 头部朝向** 可以模拟演员站在不同位置。
6. 想检查四路输出：**开始录制** → 播放 → **停止录制** → **下载 4 声道 WAV**，在 DAW 里逐轨看。

Windows 电脑也能做同样的测试：双击 **Start Simulation (Windows).cmd**（需要 Python 3.11–3.13）。

## 5. 接 M32R

### 5.1 信号链

```text
Mac ──USB──▶ M32R USB 声卡（Card 1–4）
          ──▶ M32R 通道 25–28 ──▶ Mix Bus 1–4（限幅 / EQ）
          ──▶ XLR Out 1–4 ──▶（功放，如果是无源箱）──▶ 4 只 PS15

CH1 前左 L · CH2 前右 R · CH3 后右 RR · CH4 后左 RL
```

四路必须**各自独立**到达对应音箱，**不能**混进立体声 Main LR。

### 5.2 M32R 设置

1. Setup → Config → Sample Rate：**48 kHz**。
2. Setup → Card：USB，32×32（至少 8 进 8 出）。
3. Routing → Inputs：*Inp 25–32* 来源 = **Card 1–8**。
4. 通道 25–28：关掉 LR 发送，推子 0 dB；Sends 25→Bus 1、26→Bus 2、27→Bus 3、28→Bus 4（0 dB、post）；Bus 1–4 **不要** link 成立体声。
5. Routing → Outputs：XLR Out 1–4 来源 = **MixBus 1–4**（post）。
6. Bus 1–4 打开压缩/限幅做声压保护；角落摆放低频偏重，四条 Bus 做同样的低频衰减。
7. 建一个包含 Bus 1–4 的 **Mute Group** 作为物理急停。

### 5.3 在软件里连接和逐路检查

1. USB 连好，双击启动文件。左侧 **音频设备** 点 **↻**，选 M32R（应显示 32 out），点 **连接音频**。以后启动会自动连接它。
2. 调音台 Bus 推子和功放先调低，软件 MASTER 放在 −40 dB 左右，解除 MAIN MUTE。
3. 点 **测试通道**，输入 `1`：应该是**前左**音箱响 1 秒 440 Hz；依次测 2 前右、3 后右、4 后左。对不上就改调音台路由，或在 **⚙ 舞台设置** 里改输出通道。
4. 测完打开 MAIN MUTE。
5. 电平：演员离场，用声级计在舞台中心逐路测，用 Bus 推子把四只调到一样响（可选 AutoCal，见 SHOW_GUIDE 6.5）。
6. **⚙ 舞台设置**：按实测填四只音箱相对舞台中心的 X / Y（米，+X 右、+Y 正前方），保存。

## 6. 演出操作

### 6.1 播放

| 操作 | 怎么做 | 作用 |
|---|---|---|
| ▶（每条 Cue 右边） | 点击 | 这条 Cue **从头播放，叠加**在其他声音上；正在播放时再点 = 从头重来；跳过预等待；**不改变 NEXT** |
| ■（每条 Cue 右边） | 点击 | **只把这条 Cue 淡出**，时长 = 它的「停止淡出」（默认 2 秒） |
| FADE GO | **空格** | 播放 NEXT（及自动接续的 Cue），NEXT 前进一条 |
| CUT GO | **C** | 立刻播放 NEXT，跳过预等待 |
| STOP | **S** | 所有声音 40 ms 快速停止 |
| SKIP | **Option（⌥）+ ↓** | NEXT 往后挪一条，不出声 |
| PANIC | **Shift + Esc** | 立刻切断所有声音并打开 MAIN MUTE（在输入框里也有效） |
| ⏮ 回到第一条 / 从选中 Cue 开始 / 设为 NEXT | 点按钮 | 只设定 NEXT，不出声 |

- **声音不会被动消失**：默认（左侧「播放规则」关闭）任何声音只会自己播完，或被 ■ / STOP / PANIC 停掉。开始方式为「替换」的 Cue 也按叠加播放，CUT GO 只跳过等待。需要旧的「替换」行为时，在编排模式左侧打开「允许 Cue 自动淡出其他声音」。
- 光标在输入框里时空格不触发 GO，先点一下页面空白处。
- MAIN MUTE 是静音，不是暂停：时间照常走。
- 如果提示「正在准备 NEXT 的音频…」或「音频未就绪」，先点 **✓ 预检 Preflight**。

### 6.2 编排（✎ 编排模式）

- **音频库**（左）：导入文件夹/文件，或从访达直接拖进来；单击音频 = 声音设计（电平、裁剪起止、淡入淡出、循环、立体声宽度）；双击 = 单独试听。
- **拖放建 Cue**：音频拖到舞台图 = 在落点给当前 Cue 加一层；拖到某条 Cue = 加进那条；拖到列表下方虚线框 = 新建 Cue。Cue 行可以拖动调顺序。
- **设置面板**（右下）：Cue 名称、▶ / ■、设为 NEXT；音频层表格（每层电平、延迟、静音）；当前层的运动方式（舞台位置/路径、角度+关键帧、角度 ADSR）；播放方式（Cue 电平、预/后等待、开始方式、自动接续、**停止淡出**）；存储 / 恢复 / 重置。
- **舞台图**：点击/拖动 = 当前层的位置；「＋ 添加路径点」或 Shift+点击 = 画路径；点其他颜色的圆点 = 切换到那一层。
- 每层实际电平 = 音频电平 + 层电平 + Cue 电平。所有修改约 0.3 秒后自动保存。

### 6.3 演出当天流程

开场前（提前 30 分钟）：
1. 开机顺序：调音台 → Mac → 功放/有源音箱最后开（音量先最小）。
2. 双击 **Start SpatialStage.command**；看底部提示「已自动连接并预检」。没有的话手动 **连接音频** 选 M32R，再 **✓ 预检 Preflight**。
3. 确认左侧设备是 **M32R**（不是静音模拟或耳机）。
4. Cue 列表点 **全部恢复**，确认全部 ✓。
5. 低音量点一条 Cue 的 ▶ 试听，再 ■ 停掉。
6. 点 **⏮ 回到第一条**，确认 NEXT 是第一条。
7. 调好 MASTER，解除 MAIN MUTE，关掉其他应用，打开勿扰。

紧急情况：
| 情况 | 处理 |
|---|---|
| 声音不对 | **Shift+Esc（PANIC）**，同时调音台按 **Mute Group** |
| USB 掉线 | 软件已自动静音：重新插线 → ↻ → 连接音频 → 解除 MAIN MUTE → 继续 |
| 浏览器卡住或误关 | 重新打开 `http://127.0.0.1:8765`，声音不受影响 |
| 终端被关掉 | 引擎已停：双击启动文件（会自动连接并预检）→ 选需要的 Cue → 解除静音 |

散场：
1. STOP → 打开 MAIN MUTE。
2. 关机顺序：功放/音箱 → 调音台 → Mac。
3. 备份：左侧 **⇩ 导出项目 ZIP**，并复制 `~/.spatialstage/projects/` 整个文件夹。
4. 等左侧显示 *已保存到本机*，双击 **Stop SpatialStage.command**（或终端里 Ctrl + C）。

## 7. 更新、停止、数据

**更新代码**：
1. 双击 **Stop SpatialStage.command** 停掉引擎（停不掉就到旧终端窗口按 Ctrl + C）。
2. 拉取更新：

```bash
cd ~/SpatialStage && git pull --ff-only
```

3. 双击启动文件，依赖有变化会自动重装。你在软件里做的修改不会被覆盖；`show/audio/` 新增的文件只会加进音频库。

**从旧版本切过来**（以前用过 `feat/performance-mode` 或 `main`）：

```bash
cd ~/SpatialStage && git fetch origin feat/cue-layers && git switch feat/cue-layers
```

旧项目第一次打开会自动转换成「音频库 + 单层 Cue」，位置、路径、预设都保留。如果这台 Mac 以前导入过 15 条的早期演出包，想要干净的 20 条版本，用一个新的空数据目录启动（不会删除旧项目）：

```bash
STAGE_SPATIAL_DATA=~/SpatialStage-show-v2 ./run_mac.command
```

**数据位置**：正式数据 `~/.spatialstage/projects/`；测试数据 `SpatialStage/SpatialStage-test-data/`。左下角会显示当前数据目录。不收集任何遥测或参与者数据。

## 8. 常见问题速查

| 现象 | 处理 |
|---|---|
| 设备列表里没有 M32R | USB、调音台 Card 设置、「允许配件连接」→ 点 ↻ |
| 底部提示「没有找到上次的输出设备」 | 插好 M32R，点 ↻，选它并「连接音频」 |
| 按 ▶ / GO 没反应 | 没连接输出、没预检或 MAIN MUTE 开着，看底部提示 |
| 拖音频没反应 / 改不了参数 | 处在 ▶ 演出模式，切到 ✎ 编排 |
| 只有前面两只响 | 调音台把四路混进了 Main LR，或 Bus 被 link 成立体声 |
| 方向不对 | 用「测试通道」逐路查，改路由或舞台设置里的输出通道 |
| XRUNS 增加、有爆音 | 关掉其他应用、接电源；开场前一定先预检 |
| 启动提示 *Port 8765 belongs to a different/stale engine* | 双击 Stop SpatialStage.command；不行就关掉旧终端（Ctrl + C） |
| 20 条 Cue 没出现 | `show/audio/` 不完整，用 2.2 的 `shasum` 检查 |
| 界面是英文 | 右上角 **中 / EN** |

## 9. 已知限制

- 排练原型：Python 音频回调没有硬实时保证，正式演出前要做长时间连排。
- 解码缓存上限 700 MiB，现在 20 个文件已用约 624 MiB（同一个文件被多条 Cue 使用只算一次）。再加约 3 分钟以上的新立体声素材会超限。
- 声像以舞台中心为参考，不跟踪演员；耳机虚拟监听是近似模拟，最终以现场音箱为准。
- 含循环层的 Cue 不会自己结束，要用 ■ 或 STOP 停。
- 没有暂停/继续；同一个项目只用一个浏览器窗口编辑；ZIP 只能导出备份，不能导入。
- 音频版权：见 `show/RIGHTS.md`（仓库所有者声明已获得使用和分发权）。
